# Virtual Mobile Network Operators (VMNO) Analysis
This is a work to compare the peformance between a physical MNO and its virtual MNOs.
## Notation
- M: Main (physical) operator
- V1: Virtual operator 1
- V2: Virtual operator 2
- Ln: location n (eg. L1, L2, L3)
- Rn: Run n (eg. R1, R2, R3)
- Sn: Senario n (eg. S1, S2, S3)
    |Senario|Explanation|
    |:-:|:-:|
    |S1|3 operators run in turn|
    |S2|M & V1 run together|
    |S3|M & V2 run together|
    |S4|V1 & V2 run together|
    |S5|3 operators run together|
- BOS: Boston
- PHI: Philadelphia
- ATL: Atlanta
- DL: Downlink
- UL: Uplink
